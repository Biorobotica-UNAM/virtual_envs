# gazebo_env
This repository contains a ROS2 package with files to launch a Gazebo simulation environment for robot Justina. 
All world sdf files must be located in worlds/ and 3D objects inside models/ folders.

To install Gazebo/webots libraries and dependencies for the simulation, in a new terminal run installation script as: ./install.sh

Also check webots installation guide: https://docs.ros.org/en/jazzy/Tutorials/Advanced/Simulators/Webots/Installation-Ubuntu.html
